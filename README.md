参考UC3843内部框图，基于BJT、二极管及无源器件搭建模拟PWM控制IC，实现基准电压产生、误差积分放大、锯齿波振荡、峰值电流比较、PWM锁存控制及MOSFET栅极驱动功能。采用峰值电流模式控制策略，通过电流采样电阻检测功率管峰值电流，实现逐周期过流保护；设计TL431+光耦隔离反馈网络，实现输出电压闭环稳压。完成分立PWM控制器驱动反激变换器实验验证，分析控制环路动态响应及功率器件开关特性。

- **电流镜与基准**：恒流源、带隙基准及 TL431 电压基准分析。
- **PWM 与 UC3842**：振荡器、比较器、RS 锁存、电压/电流环、软启动、欠压保护及栅极驱动设计。
- **线性稳压**：7805 类分立稳压器及启动、过流、过温等功能电路分析。
- **基础拓扑与逻辑**：PWM 生成、Bang-Bang 滞回控制、LS74 系列逻辑器件，以及电源拓扑推导。
